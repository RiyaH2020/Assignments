This repository contains my final examination project for the Applied Data Analysis course.  
The work consists of three independent, end-to-end data analysis problems, emphasizing exploratory analysis, modeling, diagnostics, and interpretation.

---

## Overview

### 1. Economic Mobility Prediction  
Analyzes whether communities with shorter average commute times exhibit higher upward economic mobility.  
Linear models, geographic controls, robust inference, and Random Forests are used to study associations and predictive performance.

### 2. Air Quality Index (AQI) Prediction  
Builds a scalable AQI prediction pipeline using high-frequency environmental sensor data.  
After extensive preprocessing and bias analysis, XGBoost achieves strong predictive accuracy, with NO₂ emerging as the dominant driver.

### 3. Movie Revenue Prediction  
Predicts box-office revenue using movie metadata, plot text, and actor-level features.  
Results show that actor popularity and structured metadata outperform text-based features, with XGBoost providing the best performance.

---

## Key Takeaways
- Careful EDA and diagnostics are essential for reliable inference  
- Tree-based and boosting models handle heterogeneous, correlated data effectively  
- Results are interpreted as associations, not causal claims
